About

What this project does

This is a demonstration of an agentic reasoning architecture built using LangGraph. It showcases intent routing, tool selection, graph execution, and transparent trace visibility.

How routing works

Queries are evaluated by an ML Intent Classifier and fallback regex rules to route into specific paths. The system builds a short execution plan and restricts formats to prevent unnecessary verbosity.
